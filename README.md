# CodSoft Python Programming Internship – Tasks

This repository contains the completed tasks for the CodSoft Python Programming internship.

| Task | Folder | Run with |
|------|--------|----------|
| 1. To-Do List | `task1_todo_list/` | `python task1_todo_list/todo.py` |
| 3. Password Generator | `task3_password_generator/` | `python task3_password_generator/password_generator.py` |
| 5. Contact Book | `task5_contact_book/` | `python task5_contact_book/contact_book.py` |

## Requirements
- Python 3.8 or newer. No third-party packages are needed.

## Notes
- The To-Do List and Contact Book save their data to JSON files next to the script
  (`todo_data.json`, `contacts.json`). These files are git-ignored.
- The Password Generator uses the `secrets` module, which is designed for security-sensitive randomness.
